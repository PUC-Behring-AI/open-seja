SEJA Documentation Collection

SEJA (Software Engineering with AI) is an agent harness that organizes human-AI collaboration through a system-isomorphic document architecture. This documentation collection is structured around five volumes, each mapping to a distinct layer of the SEJA system. It is written for a mixed audience: it pairs those layer-organized volumes with an audience-routing Reading Map, so it serves both practitioners who need task-oriented, do-it-now guidance and readers who want to understand the conceptual foundations. The intent is that a single structure works whether you arrive to get something done or to understand how and why the harness is built.

Each volume's chapters carry Diataxis section tags that classify content as tutorial, how-to, reference, or explanation. An audience-routing Reading Map helps you navigate to the content that matches your role and immediate need.

How to Read This

Diataxis Section Tags

Chapters in this collection use Diataxis-inspired section tags to classify content by its purpose. Each <section> element carries a data-diataxis attribute with one of four values:

tutorial
Learning-oriented: step-by-step lessons that guide you through a task for the first time.
how-to
Task-oriented: practical recipes for accomplishing specific goals when you already understand the basics.
reference
Information-oriented: precise, complete descriptions of components, APIs, or configuration options.
explanation
Understanding-oriented: conceptual discussions that clarify why things work the way they do.

The Reading Map

The Reading Map provides audience-routed navigation paths. Instead of reading linearly, you select your role (e.g., new user, practitioner, contributor, or researcher) and the map shows you a curated sequence of chapters that matches your goals. This is the recommended entry point for most readers.

Content Phasing

Content was developed in three phases. All phases are now complete and every chapter carries doc-status: draft. The table below records the development order for reference.

Phase Volumes Focus
Phase 1 Vol. 1 (Onboarding) + Vol. 3 (Execution Layer) Getting started and day-to-day usage -- the essential practitioner path.
Phase 2 Vol. 2 (Design Layer) + Vol. 5 (Foundations) Design philosophy and intellectual foundations -- the conceptual depth path.
Phase 3 Vol. 4 (Governance Layer) Output management, enforcement, and release -- the operational maturity path.

Vol. 2: The Design Layer Phase 2

This volume explains how SEJA encodes design decisions as first-class artifacts. The design layer is where the human designer's intent -- expressed through metacommunication, a project constitution, design-intent specs, and semiotic markers -- becomes the authoritative source that drives every downstream execution and governance decision. Understanding this layer is essential for anyone who wants to shape how an agent behaves, not just use it.

Chapters

  1. 1. The Metacommunication Message What a metacommunication message is in semiotic engineering, how to write one using the Extended Metacommunication Template questionnaire, and the I/you phrasing rule that structures designer-to-user communication. Includes a worked example for a task manager project.
  2. 2. The Constitution The project constitution's four-section structure (Technical Principles, Quality Principles, Security Invariants, Compliance Requirements), how to write and maintain one, and why immutable principles loaded before all other references are essential for governing agent behavior.
  3. 3. Design Intent Files The as-intended/as-coded split that separates designer vision from implementation state, the full section structure of product-design-as-intended.md, and the promote workflow for advancing items from implemented to established status.
  4. 4. The Marker System The three marker types (STATUS, INCORPORATED, DECISION_APPEND/CHANGELOG_APPEND), how to apply them using apply_marker.py, and how markers function as a designed signification system that enforces the boundary between human-authored prose and agent-maintained lifecycle state.
  5. 5. UX Research Artifacts Personas, problem scenarios, and discovered journeys -- the structured UX research artifacts that ground SEJA projects in evidence about target users. Covers the distinction between discovered journeys (JM-E-NNN, evidence from field observation) and designed journeys (JM-TB-NNN, planned by the designer).

Recommended Reading Order

Begin with "The Metacommunication Message" to understand the foundational communication model and the I/you phrasing rule, then "The Constitution" to see how immutable principles govern agent behavior, and "Design Intent Files" to learn the as-intended/as-coded split. "The Marker System" shows how lifecycle state is tracked without altering human-authored prose. "UX Research Artifacts" rounds out the volume with the personas, problem scenarios, and journey observations that ground design in evidence. Readers already familiar with semiotic engineering may skip ahead to "The Constitution."

Related Volumes

The design layer feeds directly into Vol. 3: The Execution Layer, where skills and lifecycle stages implement the designer's intent. For the semiotic engineering theory that underpins this layer, see Vol. 5: Foundations and Philosophy.

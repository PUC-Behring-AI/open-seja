Vol. 3: The Execution Layer Phase 1

This volume covers day-to-day usage of SEJA -- the lifecycle pipeline that orchestrates work, the skill system that encapsulates agent capabilities, subagent delegation for parallel tasks, plan-driven implementation, and the quality critique loop. This is the practitioner's primary reference for getting work done with SEJA.

Chapters

  1. 1. Lifecycle Pipeline Documents the canonical lifecycle path from /research through /reflect, the 6 pre-skill stages and post-skill steps that bookend every skill invocation, enforcement mechanisms (CLAUDE.md rules, pre-commit hooks, validation scripts), lifecycle variations for bug fixes, documentation-only tasks, and refactoring, and the conversation trace protocol for non-skill exchanges.
  2. 2. Skills In Depth Per-skill reference for all 15 user-facing skills, covering purpose, parameters, prerequisites, workflow summary, subagent delegations, reference file loads, expected outputs, and common mistakes. Opens with a skill system overview explaining the dispatch mechanism and context budget tiers (light, standard, heavy).
  3. 3. Subagent Delegation Explains how skills delegate specialized work to subagents via the Agent tool, with a per-agent reference for all 16 agents: 9 evaluators (code-reviewer, council-debate, harness-health-evaluator, migration-validator, plan-reviewer, research-reviewer, semiotic-inspector, standards-checker, test-runner) and 7 generators (communication-generator, onboarding-generator, document-generator, test-plan-generator, explanation-generator, architecture-explainer, evolution-explainer). Includes a guide for writing custom subagents.
  4. 4. Plans and Implementation Covers plan file structure (header, step format with Files/Verify/Tests/Docs/Traces metadata), the three planning modes (standard, lightweight proposal, roadmap), the complexity-gated two-phase review process, and the /implement executor with auto, manual, roadmap, and pending modes. Also documents progress tracking, checkpoint recovery, and design-intent traceability via Traces fields and STATUS markers.
  5. 5. Quality and Critique Documents the /critique skill's 10 modes (validate, review, smoke, preflight, health, test-plan, docs, freshness, telemetry, semiotic-inspection), the 16 review perspectives organized into Essential, Standard, and Deep tiers, the two-phase review process (perspective triage and scan followed by targeted deep-dives), and guidance for interpreting critique results.

Recommended Reading Order

Start with "Lifecycle Pipeline" to understand the overall flow, then "Skills In Depth" for the mechanism that powers each stage. Read "Subagent Delegation" next to understand how complex tasks are parallelized, then "Plans and Implementation" for the planning workflow. Finish with "Quality and Critique" to learn how SEJA validates its own outputs.

Related Volumes

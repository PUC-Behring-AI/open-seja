Vol. 1: Onboarding and Orientation Phase 1

This volume is the entry point for anyone new to SEJA. It introduces what the harness is, walks you through your first project setup, and provides navigational aids -- a reading map and glossary -- so you can find your way through the rest of the collection efficiently. Start here before diving into any other volume.

Chapters

  1. 1. What SEJA Is (and Is Not) Positions SEJA as an agent harness -- a governance layer for Claude Code grounded in semiotic engineering. Distinguishes the agent from the harnessed agent, explains how design intent anchors all decisions, and previews the dual thesis that SEJA is both governable and epistemic.
  2. 2. Quickstart The fastest path from zero to a working SEJA project. Covers two setup paths (clone or install into existing project), walks through your first design-plan-implement cycle with concrete commands, and maps the experience to the full canonical lifecycle.
  3. 3. Reading Map Audience-routed navigation paths that guide you to the chapters most relevant to your role and goals.
  4. 4. Glossary and Shared Definitions A curated orientation to the most important SEJA terms, organized into three domains: core terms (skills, plans, design intent), semiotic engineering terms (metacommunication, signs, communicability), and lifecycle terms (pre-skill, post-skill, drift, markers). Each definition cross-references the chapter that covers it in depth.

Recommended Reading Order

Read the chapters in sequence: start with "What SEJA Is" to understand the big picture, then "Quickstart" to get hands-on experience, then "Reading Map" to plan your journey through the rest of the collection. The "Glossary" serves as a reference you can consult at any time.

Related Volumes

After completing this volume, continue with Vol. 3: The Execution Layer to start using SEJA day-to-day. For the theoretical foundations behind the harness design, see Vol. 5: Foundations and Philosophy.

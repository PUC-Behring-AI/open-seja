Vol. 2: How-To Guides -- "Use SEJA"

Task-oriented, goal-first guides for people who already know what they want to accomplish and need the steps to get there. Where the tutorials teach by walking you through a guaranteed outcome, the how-to guides assume you have a specific objective -- install the harness a particular way, run a single skill, flip a governance marker, reconcile design intent, or extend the harness -- and give you the shortest reliable path to that goal. Each guide states its objective up front, lists the prerequisites, and moves directly to the actions.

How to Use This Volume

Unlike the tutorials, the how-to guides are not meant to be read in order. Jump straight to the chapter that matches your current goal:

  • Setting up SEJA in a project for the first time? Start with Ch. 1: Installation and Setup.
  • Need to run one skill and want the exact steps? Go to Ch. 2: Skill-by-Skill Guides and pick the skill.
  • Managing pending actions or curating governance state? See Ch. 3: Governance Operations.
  • Keeping design intent aligned with the code? See Ch. 4: Design Intent Maintenance.
  • Extending or reconfiguring the harness? See Ch. 5: Customization and Extension.

If you have never used SEJA before, the how-to guides assume a working project. Complete Vol. 1: Tutorials first to establish that project, then return here when you have a specific task in hand. When a guide references a component in depth -- a skill's full argument set, a script's parameters, a file format -- it links to the exhaustive specification in Vol. 3: Reference.

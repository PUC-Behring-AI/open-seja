Reference Files Catalog

SEJA reference files provide the context that skills and agents need to make informed decisions. They are organized into three groups by scope: general references (shared across all projects), template references (used to generate project-specific files), and project-specific references (generated per-project by /design). This catalog documents every reference file, its load mechanism, consumer skills, and maintainer classification.

Load Mechanisms

Eager (mandatory)
Always loaded by pre-skill ref-load stage for standard and heavy context budget tiers. These files are injected into every skill invocation: conventions.md, permissions.md, constraints.md.
Eager (skill-declared)
Loaded immediately when declared in a skill's metadata.eager_references field. Injected alongside the mandatory refs before the skill body executes.
Lazy (demand-pull)
Listed in the "Available references" block but not injected until the skill requests them during execution. Used when a skill declares metadata.eager_references (Mode 2 demand-pull).
Eager-only (legacy)
When a skill has no metadata.eager_references field (Mode 1), all entries in metadata.references are loaded eagerly.
Manual
Not loaded automatically by pre-skill. Read on demand by specific skills, agents, or scripts when needed.

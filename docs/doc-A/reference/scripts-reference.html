Scripts Reference

Overview

The SEJA harness includes 93 Python scripts distributed across .claude/skills/scripts/ (shared utilities) and co-located skill subdirectories (skill-owned scripts that live next to their SKILL.md). Scripts are organized into six functional categories: validation, generation, lifecycle/markers, utility, conversion, and migration/setup.

All scripts use Python 3 and follow the conventions in .claude/references/general/coding-standards.md and .claude/references/general/script-header-convention.md. Scripts that serve as CLI entry points declare their interface via argparse and follow a standard exit-code convention: 0 = success/pass, 1 = failures/violations found, 2 = script error.

Script Locations

.claude/skills/scripts/
Shared utility scripts available to all skills and hooks.
.claude/skills/scripts/priv/
Private-only scripts that are never synced to the public repository.
.claude/skills/<skill-name>/
Skill-owned scripts co-located with their parent skill's SKILL.md.

Validation Scripts

Scripts that check, verify, or validate harness state, code quality, or configuration consistency. Many are wired into run_preflight_fast.py (pre-commit hook) or run_all_checks.py (CI orchestrator).

Exit Code Convention

All CLI scripts follow a standard three-value exit code convention:

Exit Code Meaning Action
0 Success / Pass All checks passed or operation completed successfully.
1 Failures / Violations Found The script ran correctly but found issues. Check output for details.
2 Script Error The script itself failed (missing dependency, file not found, parse error). Investigate the script, not the checked content.

Exception: conversation_trace.py uses exit code 2 for "masking confirmation required" (the script detected sensitive content and needs the caller to re-run with --confirm).

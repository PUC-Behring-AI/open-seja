Volume 3: Reference -- "Look Up SEJA"

Exhaustive specification of every SEJA component: skills, subagents, scripts, reference files, pipelines, file formats, and configuration variables. Each chapter provides tabular, parameter-level detail designed for lookup rather than sequential reading.

Chapters

# Chapter Contents
1 Skills Reference All 17 skills (15 user-facing + 2 internal). Per-skill tables with arguments, modes, exit behavior, subagent delegations, and context budget tiers.
2 Subagent Reference All 16 subagent prompts: 9 evaluators and 7 generators. Per-agent tables with inputs, outputs, trust boundaries, and invoking skills.
3 Scripts Reference All helper scripts organized by location (shared utilities vs. skill-owned) and by function (validation, generation, lifecycle management, migration).
4 Reference Files Catalog Complete inventory of reference files across three groups: general (50 files), template (50 files), and project-specific. Load mechanisms, consumer skills, and maintainer classification.
5 Pipeline Reference Pre-skill pipeline (6 stages) and post-skill pipeline (13+ steps). Stage-level detail: criticality, skip conditions, inputs, outputs, error handling.
6 File Format Reference Every file format used in SEJA: YAML frontmatter schemas, JSONL record formats, Markdown structures, plan/advisory/roadmap/brief conventions.
7 Configuration Reference All configuration variables from conventions.md, constitution.md, and settings.json. Directory structure variables, key file variables, periodic trigger thresholds, and Claude Code hook configuration.

How to Use This Volume

This volume is structured for lookup, not sequential reading. Start from the chapter that matches what you need to find:

  • What arguments does a skill accept? → Ch. 1: Skills Reference
  • What does an agent expect as input? → Ch. 2: Subagent Reference
  • What does a script do and how do I call it? → Ch. 3: Scripts Reference
  • Where is a reference file and who uses it? → Ch. 4: Reference Files Catalog
  • What happens during pre-skill or post-skill? → Ch. 5: Pipeline Reference
  • What fields go in a plan header? → Ch. 6: File Format Reference
  • What variables can I set in conventions.md? → Ch. 7: Configuration Reference

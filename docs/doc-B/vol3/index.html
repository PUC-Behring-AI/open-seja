Vol. 3: The Execution Layer Phase 1

This volume is in draft status. Chapter content has been written for Phase 1; editorial review is pending.

This volume covers day-to-day usage of SEJA -- the lifecycle pipeline that orchestrates work, the skill system that encapsulates agent capabilities, subagent delegation for parallel tasks, plan-driven implementation, and the quality critique loop. This is the practitioner's primary reference for getting work done with SEJA.

Chapters

  1. 1. The Lifecycle Pipeline Documents the three-phase pipeline that wraps every skill invocation: pre-skill, skill execution, and post-skill. Covers the canonical skill ordering, enforcement mechanisms, lifecycle variations, and conversation trace integration.
  2. 2. Skills In Depth Per-skill reference for all user-facing skills and internal lifecycle hooks. Each entry follows a consistent template: purpose, parameters, prerequisites, workflow summary, subagent delegations, reference file loads, expected outputs, and common mistakes.
  3. 3. Subagent Delegation Explains the thin-orchestrator delegation model that separates skill-level coordination from engine-level work. Provides per-agent reference cards for evaluators and generators, covering agent prompt file format, trust boundaries, and result processing.
  4. 4. Plans and Implementation Covers the anatomy of a plan file, planning modes, complexity-gated review, and the /implement executor with its execution modes. Documents progress tracking, checkpoint recovery, rollback branches, and design-intent traceability.
  5. 5. Quality and Critique Documents the /critique skill's modes and the review perspectives organized into Essential and Deep-dive tiers. Explains the two-phase review process, stack-based filtering, conflict resolution between perspectives, and how to interpret validation results.

Recommended Reading Order

Start with "Lifecycle Pipeline" to understand the overall flow, then "Skills In Depth" for the mechanism that powers each stage. Read "Subagent Delegation" next to understand how complex tasks are parallelized, then "Plans and Implementation" for the planning workflow. Finish with "Quality and Critique" to learn how SEJA validates its own outputs.

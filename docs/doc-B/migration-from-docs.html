Migration from the Existing Docs

This page is informational. It maps the content of the existing SEJA public documentation set (the docs/ tree that ships in the public seja repository) onto the five-volume system-isomorphic collection you are reading now. Its purpose is to help a reader who knows the old docs find the equivalent material here, and to make the reorganization legible.

This is not a plan to delete or retire the existing docs. The docs/ tree is preserved and remains the canonical, release-bound documentation set. This collection is complementary: it reorganizes and expands the same underlying material into a system-isomorphic volume structure, and it adds conceptual depth (the Foundations volume) that the flat docs tree treats more briefly. Where a chapter in this collection and an existing doc cover the same ground, treat the existing doc as authoritative for exact command syntax and release-bound details, and treat the chapter in this collection as the narrative, teaching-oriented companion.

How to Read the Mapping

The table is grouped by directory in the existing docs tree (docs/, docs/how-to/, docs/concepts/, docs/reference/) plus the repository top-level entries. Each row records where the existing document's content now lives in this collection and the nature of the relationship:

Superseded
The chapter in this collection covers the same material more fully or as part of a larger narrative. The existing doc is still preserved, but the chapter in this collection is the fuller treatment of that topic here.
Complementary
Both cover related ground from different angles. The existing doc remains the go-to for its specific task or lookup; the chapter in this collection adds context or teaches the concept behind it.
Standalone
The existing doc has no direct equivalent in this collection. It is typically a generated artifact, a machine-readable data file, or a contributor-facing detail that sits outside this collection's scope.

Content Without a Direct Existing-Doc Source

Some chapters in this collection have no single existing-doc counterpart because they draw material together from the harness itself rather than from the flat docs tree. The clearest examples are Vol. 1, Ch. 3: Reading Map (a navigation aid specific to this collection), Vol. 2, Ch. 1: The Metacommunication Message, and the later Foundations chapters (Vol. 5, Ch. 3, Ch. 4, Ch. 5, Ch. 7). These expand the brief treatment in docs/foundations.md and docs/concepts.md into standalone chapters.

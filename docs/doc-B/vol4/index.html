Volume 4: The Output and Governance Layer Phase 3

This volume is in draft status. Chapter content has been written for Phase 3; editorial review is pending.

Everything about what SEJA produces, how it enforces discipline, and how to keep a project healthy over time. This volume covers the output directory and its artifacts, the multi-layer enforcement architecture that guards the priv/public boundary, the shared helper scripts and validation suite, the maintenance and drift-alignment workflows, and the release-and-publishing pipeline. It is the reference for the governance side of the harness -- the machinery that keeps outputs auditable and a project trustworthy across iterations.

Chapters

  1. 1. Output Artifacts Covers the output directory tree, the artifact types SEJA produces and their lifecycle, and the audit trail formed by the briefs log and the conversation trace.
  2. 2. Enforcement Architecture Explains the multi-layer enforcement model, file-maintainer classification, leak prevention, the priv/public boundary, and the anti-patterns the architecture is designed to catch.
  3. 3. Scripts and Automation A reference for the key shared helper scripts and a guide to how to run and extend the validation suite.
  4. 4. Maintenance and Drift Documents freshness policies, periodic triggers, and the /explain drift alignment workflow that reconciles design specs with the as-coded state.
  5. 5. Release and Publishing Walks through the /publish pipeline, the tag conventions, and the ephemeral publish workspace used to build a public release.

Recommended Reading Order

Start with "Output Artifacts" to understand what SEJA produces and where it lives, then read "Enforcement Architecture" for the model that keeps those artifacts and the priv/public boundary safe. "Scripts and Automation" grounds both in the concrete helpers and validation suite. Finish with "Maintenance and Drift" and "Release and Publishing" for the workflows that keep a project healthy over time and ship it outward.

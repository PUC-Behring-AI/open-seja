Vol. 1: Onboarding and Orientation Phase 1

This volume is in draft status. Chapter content has been written for Phase 1; editorial review is pending.

This volume is the entry point for anyone new to SEJA. It introduces what the harness is, walks you through your first project setup, and provides navigational aids -- a reading map and glossary -- so you can find your way through the rest of the collection efficiently. Start here before diving into any other volume.

Chapters

  1. 1. What SEJA Is (and Is Not) Explains SEJA's positioning as a harness (not a framework or platform), contrasts the raw agent with the harnessed agent, and introduces the three capabilities the harness provides: lifecycle discipline, design-intent alignment, and epistemic scaffolding.
  2. 2. Quickstart A hands-on tutorial that walks you through cloning the SEJA repository, running /seja-setup --here to finalise the harness, configuring your project with /design, and executing your first lifecycle cycle.
  3. 3. Reading Map Audience-routed navigation paths that guide you to the chapters most relevant to your role and goals. Defines audience profiles, question types, and provides both a visual decision tree and a flat lookup table with direct links.
  4. 4. Glossary Alphabetical reference of key terms across three categories: core terms, semiotic engineering terms, and lifecycle terms. Each entry includes cross-references to the chapters where the concept is covered in depth.

Recommended Reading Order

Read the chapters in sequence: start with "What SEJA Is" to understand the big picture, then "Quickstart" to get hands-on experience, then "Reading Map" to plan your journey through the rest of the collection. The "Glossary" serves as a reference you can consult at any time.

Related Volumes

After completing this volume, continue with Vol. 3: The Execution Layer to start using SEJA day-to-day. For the theoretical foundations behind the harness design, see Vol. 5: Foundations.

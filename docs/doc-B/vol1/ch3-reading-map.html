Reading Map

This page helps you find the right content for your role and your immediate question. Instead of reading the entire collection linearly, use the decision tree below to identify your audience profile, then follow the recommended path to the volumes and chapters that match your goals.

The Reading Map also serves as Chapter 3 of Vol. 1: Onboarding and Orientation.

Audience Profiles

A. New User
You have never used SEJA before. You want to understand what the harness is, install it, and run your first project.
B. Experienced User
You have a working SEJA project. You want task-oriented guidance on specific skills, the lifecycle pipeline, or day-to-day operations.
C. Advanced User / Contributor
You want to extend, customize, or contribute to SEJA. You need to understand the enforcement architecture, scripting internals, and release process.
D. Academic / Researcher
You are interested in the semiotic engineering foundations, the metacommunication theory, or the epistemic thesis behind the harness design.
E. AI Agent Reader
You are an AI agent processing the harness documentation programmatically. You need to understand the sign system, the marker conventions, and how to read the harness as a metacommunication message.

Question Types

Q1. How do I get started?
Installation, first project, initial orientation.
Q2. How do I use skill X?
Task-oriented guidance for specific skills and workflows.
Q3. How does the harness work internally?
Architecture, enforcement, scripts, and governance.
Q4. What is the theory behind this?
Semiotic engineering foundations, metacommunication, epistemic design.
Q5. How do I extend or customize?
Contributing, adding skills, modifying governance, release process.

Start at the top. Pick your audience profile (A--E), then follow the branch for your question (Q1--Q5) to find the recommended volume and chapter.

Recommended Reading Paths

If you prefer a guided sequence rather than individual chapter lookups, these curated paths give you a coherent reading order for each audience profile.

  • A. New User Path

    From zero to working project, then understanding why it works.

    1. What SEJA Is -- understand the big picture
    2. Quickstart -- install and run your first project
    3. Lifecycle Pipeline -- learn the canonical skill sequence
    4. Skills in Depth -- explore individual skills
    5. Software as Communication -- optional theory grounding

  • B. Experienced User Path

    Deepen your day-to-day practice and understand the design behind it.

    1. Skills in Depth -- master specific skills
    2. Plans and Implementation -- plan-driven development
    3. Quality and Critique -- validation and review
    4. Metacommunication -- why the harness communicates this way
    5. Maintenance and Drift -- keeping your project healthy

  • C. Advanced User / Contributor Path

    Understand the internals so you can extend and contribute.

    1. Enforcement Architecture -- how rules are enforced
    2. Scripts and Automation -- the helper script ecosystem
    3. Subagent Delegation -- agent orchestration patterns
    4. Marker System -- the lifecycle marker convention
    5. Release and Publishing -- the release pipeline

  • D. Academic / Researcher Path

    Explore the theoretical foundations and research connections.

    1. Software as Communication -- the semiotic engineering premise
    2. Sign Systems -- signs, classes, and interpretants
    3. Extended Metacommunication -- extending the theory to AI agents
    4. Reflective Practice -- reflection-in-action for harness design
    5. Abduction and Plural Readings -- abductive reasoning in design
    6. Governable Epistemic -- the governance thesis

  • E. AI Agent Reader Path

    Understand the harness as a sign system you can read and act on.

    1. Agent Reads Harness -- how an AI agent interprets SEJA
    2. Sign Systems -- the sign classes you will encounter
    3. Marker System -- machine-readable markers and their semantics
    4. Lifecycle Pipeline -- the skill execution sequence
    5. Enforcement Architecture -- constraints that govern agent behavior

How to Use This Map

Tip: You do not need to read every chapter. Pick the audience profile that fits you best, start with the "Start Here" column in the lookup table, and follow the "Then Read" links as your needs evolve. The Glossary is available as a reference at any point in your reading.

The decision tree and lookup table present the same information in two formats: the tree gives a visual overview of how audiences and questions branch, while the table provides a direct link for each combination. If you are unsure which audience profile fits you, start with the New User path -- it provides the broadest foundation.

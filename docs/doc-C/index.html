A shared core, three audience tracks

This collection is organised around one idea: everyone reads the same core documentation — the Skills, Concepts, Operations, and Reference pages that describe how the SEJA harness actually works — but few readers need all of it in the same order. A first-time user, a systems architect, and a semiotics scholar are looking at the same harness with very different questions in mind.

So the core is wrapped in three audience tracks. Each track is a curated route through the shared core, opened by a short gate page that sets context and hands you a reading sequence: Practitioner (get things done), Architect (understand the structure), and Scholar (understand the theory). Tracks do not fork the content — they only recommend an order. Use the decision tree below to find your starting point, or skip straight to any core section.

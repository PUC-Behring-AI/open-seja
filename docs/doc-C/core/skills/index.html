skills how-to

Understand and intend

Investigate what you are about to change and fix the intent before you touch code.

Research how-to
Answer questions about the codebase, architecture, or design decisions, logging each Q&A pair — and, with --inventory, catalog codebase elements matching a pattern.
Explain how-to
Explain behavior, code, data model, architecture, or spec drift with visual diagrams and analogies; /explain drift reconciles design specs with the as-coded state.
Design how-to
Define or update the project design — stack, conventions, domain model, conceptual design, and standards — when intent needs to change.
Plan how-to
Build a plan to add a feature, fix a bug, or refactor, breaking the work into structured steps; supports metacommunication framing for design-intent briefs.

Build and validate

Execute the plan, put it through the quality gates, and produce the material that goes out with it.

Implement how-to
Execute a previously generated plan across auto, manual, and roadmap modes to add a feature, fix a bug, or refactor.
Critique how-to
Run the quality gates: validation, code review, smoke tests, preflight, and harness health, with stack filtering and a --depth override.
Document how-to
Generate or update user and developer documentation from plan Docs: fields, auto-detection, or an explicit type selection.
Communicate how-to
Generate stakeholder communication material tailored to a specific audience segment, in Markdown, HTML, or both.

Deliver and manage

Ship the release, manage the harness and the team around it, and keep the workspace honest.

Reflect how-to
Reflect on specific plans, research reports, or other artifacts — on the product built or the practice used — recording your words verbatim.
Publish how-to
Cut a tagged release and push it to the public SEJA repository via the automated publish pipeline, with a --dry-run preview.
Seja-setup how-to
Manage the harness: install into a new or existing codebase, finalise an in-place download, create a companion workspace, bootstrap a demo, or upgrade harness files.
Onboard how-to
Generate a tailored onboarding plan for a new team member based on their role family and expertise level.
Pending how-to
List and address outstanding human actions from the pending ledger: verify implementations, flip status markers, run periodic curation, and manage deferred work.
Qa-log how-to
Log the entire current question-and-answer session into a file for future reference.
Help how-to
Show contextual help, browse skills by category, or get details on a specific skill.

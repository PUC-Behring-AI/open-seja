What it does

/qa-log saves the entire current Q&A session — all user prompts and agent responses, in chronological order — to a file for future reference. In standalone mode it reserves a globally unique ID, derives a short-title slug from the conversation topic (or from an argument you provide), and writes a timestamped Markdown file to _output/qa-logs/ using the pattern qa-<id>-<slug>.md.

The log carries a dated header, a one-line brief summarising the session, and a numbered Q&A section; lengthy agent responses (such as code generation) are summarised rather than reproduced in full. The skill also runs in companion mode when a lifecycle caller such as /post-skill invokes it: the caller may override the output directory and filename so the log lives next to the artifact it documents, but the datetime field is never overridden, keeping every log indexable by date.

When to run it

Run /qa-log when you have had a productive conversation with useful decisions or insights and want to preserve it as project documentation. Pass a short title as the argument (for example, /qa-log Design decisions for the notification system) to name the file explicitly; omit it to have the title derived from the conversation topic.

Most lifecycle skills capture their own Q&A automatically through post-skill, so standalone /qa-log is for ad-hoc conversations that would otherwise leave no record.

How it fits the lifecycle

/qa-log is a housekeeping utility that sits off the main lifecycle spine rather than at a fixed stage on it. The canonical path — /research → /design | /plan → /implement → /critique → /document | /communicate → /reflect — already captures Q&A for its own artifacts; /qa-log supports the cases those stages do not cover.

Its two roles are complementary: standalone, it preserves an unstructured conversation on demand; behind the scenes, post-skill uses the same skill in companion mode to collocate a Q&A record next to the parent artifact. If a conversation raises further questions after you capture it, /research is the natural next step.

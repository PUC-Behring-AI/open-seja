Overview

SEJA ships sixteen subagent prompts in .claude/agents/, organized by role. Evaluator agents (9) review artifacts against quality perspectives. Generator agents (7) produce self-contained artifacts from well-defined inputs; they are invoked by thin-skill wrappers and must receive the project constitution as part of their prompt for trust-boundary enforcement. Each agent runs in an isolated context window and is restricted to the tools listed in its frontmatter. The Tools column below reproduces each agent's allowed-tools list verbatim.

Evaluator agents (9)

Evaluator agents review code, plans, decisions, migrations, tests, and the harness itself, reporting findings rather than mutating artifacts.

The nine evaluator subagents.
Agent Role Description Tools
code-reviewer Evaluator Reviews code changes against engineering and design perspectives (depth-gated — deep evaluates all 16; standard/light use a shortlisted subset). Reports findings with Adopted/Deferred/N/A status per perspective. Read, Glob, Grep, Bash
council-debate Evaluator Runs a structured expert council debate for high-stakes design decisions. Five fixed archetypes plus 0-2 brief-specific experts surface trade-offs, tensions, and insights through position statements and cross-examination. Read, WebSearch
harness-health-evaluator Evaluator Runs harness self-diagnosis across 9 built-in checks (skill system, briefs hygiene, plans hygiene, references, conventions, constitution, spec compliance, pending ledger, harness drift) and produces a Harness Health Report. Read, Bash, Grep, Write
migration-validator Evaluator Validates Alembic migration chain integrity, checks for idempotency issues, PostgreSQL syntax problems, and common migration pitfalls. Read, Bash, Glob, Grep
plan-reviewer Evaluator Reviews a plan against engineering and design perspectives using the complexity-gated two-phase review process. Returns the review log and any plan amendments. Read, Glob, Grep, Bash
research-reviewer Evaluator Evaluates design decisions, open-ended questions, and trade-offs against engineering and design perspectives. Unlike code-reviewer (diffs) and plan-reviewer (structured plans), research-reviewer handles research questions and recommendations. Read, Glob, Grep, WebSearch
semiotic-inspector Evaluator Conducts a Semiotic Inspection Method (SIM) evaluation of a project's interface communicability across metalinguistic, static, and dynamic sign classes. Read, Glob, Grep, Write
standards-checker Evaluator Runs all project validation scripts and aggregates results into a unified compliance report. Read, Bash, Glob, Grep
test-runner Evaluator Runs backend (pytest) and frontend (vitest) test suites, parses output, and reports failures with context including file, line, and error message. Read, Bash, Glob, Grep

Generator agents (7)

Generator agents produce self-contained artifacts — communication material, onboarding plans, documentation, test plans, and explanation reports — invoked by thin-skill wrappers that handle argument parsing, interactive prompts, and lifecycle hooks.

The seven generator subagents.
Agent Role Description Tools
communication-generator Generator Generates tailored communication material for a specific audience segment. Produces Markdown and/or HTML output files. Invoked by the /communicate skill (thin wrapper). Read, Bash, Glob, Grep, Write
onboarding-generator Generator Generates a tailored onboarding plan for a new team member based on role family, expertise level, and project context. Invoked by the /onboard skill (thin wrapper). Read, Bash, Glob, Grep, Write
document-generator Generator Generates or updates project documentation for a specific documentation type (readme, contextual-help, api-reference, ddr, help-center, changelog, spo). Invoked by the /document skill (thin wrapper). Read, Bash, Glob, Grep, Write
test-plan-generator Generator Generates a structured manual test plan from a brief and the most recent DONE plans. Read, Glob, Grep, Write
explanation-generator Generator Generates explanation reports for the behavior, code, and data-model modes of the /explain skill. Invoked by the /explain skill (thin wrapper). Read, Glob, Grep, Bash, WebSearch, Write
architecture-explainer Generator Generates architecture explanation reports for the /explain skill. Invoked by the /explain skill (thin wrapper). Read, Glob, Grep, Bash, WebSearch, Write
evolution-explainer Generator Generates behavior-evolution explanation reports for the /explain skill. Invoked by the /explain skill (thin wrapper). Read, Glob, Grep, Bash, WebSearch, Write

Overview

SEJA defines seventeen skills in .claude/skills/<name>/SKILL.md: fifteen user-facing skills and two internal lifecycle hooks (pre-skill and post-skill) that are not directly invocable. The Context Budget column reports each skill's metadata.context_budget tier, which pre-skill's budget-eval stage reads to decide how many briefs and reference files to load: light loads none, standard loads the briefs index, and heavy loads full briefs with recency windowing plus the plan index.

Canonical lifecycle path

The skills are grouped below by category, not lifecycle order. The canonical lifecycle path — validate before you communicate — is:

/research (or /explain) → /design | /plan → /implement → /critique → /document | /communicate → /reflect.

User-facing skills (15)

These fifteen skills are invocable directly by the user. Each ships a SKILL-quickguide.md sibling with a designer-friendly description, example, and usage scenario.

The fifteen user-facing skills.
Skill Name Description Category Context Budget User-Invocable
research Answer questions about the codebase, architecture, or design decisions, logging Q&A pairs. With --inventory, catalog codebase elements matching a pattern. user-facing standard Yes
explain Explains behavior, code, data model, architecture, or spec drift with visual diagrams and analogies. user-facing standard Yes
design Define or update project design — stack, conventions, domain model, conceptual design, and standards. user-facing standard Yes
plan Make a plan to add a feature, fix a bug, or refactor code. Supports metacomm framing for design-intent briefs. user-facing heavy Yes
implement Execute a previously generated plan to add a feature, fix a bug, or refactor code. user-facing heavy Yes
critique Critique quality: validation, code review, smoke tests, preflight, and harness health. user-facing heavy Yes
document Generate or update project documentation based on plan Docs: fields, auto-detection, or explicit type selection. user-facing standard Yes
communicate Generate tailored communication material for a specific audience segment. user-facing standard Yes
reflect On-demand reflection anchored on specific plans, research reports, or other artifacts, recording the designer's words verbatim. user-facing standard Yes
onboard Generate a tailored onboarding plan for a new team member based on their role and expertise level. user-facing standard Yes
seja-setup Manage the SEJA harness in this project: install, finalise an in-place download, create a companion workspace, bootstrap a demo project, or upgrade harness files. user-facing standard Yes
pending List and address outstanding human actions from the pending ledger: verify implementations, flip status markers, run periodic curation, manage deferred work. user-facing light Yes
publish Publish a tagged release to the public SEJA repository via the automated publish pipeline. user-facing light Yes
help Show contextual help, browse skills by category, or get details on a specific skill. user-facing light Yes
qa-log Log the entire current Q&A session into a file for future reference. user-facing light Yes

Internal lifecycle hooks (2)

These two skills are internal lifecycle hooks — carrying user-invocable: false and the [Internal] prefix — invoked by other skills rather than by the user directly.

The two internal lifecycle-hook skills.
Skill Name Description Category Context Budget User-Invocable
pre-skill [Internal] Lifecycle hook invoked by other skills to load references and log briefs. Runs the six-stage pre-skill pipeline. internal standard No
post-skill [Internal] Lifecycle hook invoked by other skills for briefs update, QA logging, and git commit. internal standard No

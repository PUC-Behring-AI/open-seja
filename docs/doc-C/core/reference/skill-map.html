Overview

This page extracts the skill-type nodes and their relational edges — invokes (skill → script), delegates (skill → subagent), and orchestrates (skill → lifecycle hook) — from the same harness topology summarized in the Call Graph reference. There are seventeen skill nodes: fifteen user-facing skills plus the two internal lifecycle hooks, /pre-skill and /post-skill. The tables below are static; there is no runtime fetch.

Lifecycle path and delegation patterns

The skill nodes trace the canonical lifecycle path:

/research (or /explain) → /design | /plan → /implement → /critique → /document | /communicate → /reflect.

Two structural patterns stand out in the edge data:

  • The hook sandwich. Every skill that mutates state — /research, /plan, /implement, /critique, /communicate, /onboard, /publish — orchestrates both /pre-skill (at entry) and /post-skill (at exit). Read-lean or pre-skill-only skills (/design, /pending) orchestrate just /pre-skill. /post-skill then carries the heaviest script fan-out (10 invokes), because state alignment, index regeneration, gates, and telemetry all live there.
  • Evaluator vs. generator delegation. /critique is the heaviest delegator (7 evaluator agents), and /research adds two more evaluators (council-debate, research-reviewer). The generator skills each delegate to exactly one matching agent: /document and /publish → document-generator, /communicate → communication-generator, /onboard → onboarding-generator, /explain → its three explainer agents, and /plan / /implement → plan-reviewer / test-runner respectively.

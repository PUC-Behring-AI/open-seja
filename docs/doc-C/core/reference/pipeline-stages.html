Overview

Every SEJA skill invocation is bracketed by two internal lifecycle hooks: pre-skill runs first (loading references and logging the brief), and post-skill runs last (aligning state, logging Q&A, and committing). This page is the exhaustive per-stage and per-step lookup for both pipelines.

Boundary note. This page is the exhaustive lookup — the complete table of stages, steps, and their gate conditions. The conceptual model of why the lifecycle is shaped this way lives in the Concepts sibling The Lifecycle Pipeline. Read that page for the mental model; consult this one to look up a specific stage or step.

Pre-skill pipeline

Pre-skill runs six composable stages. Three are critical (always run): brief-log, budget-eval, and ref-load. The other three are non-critical — error-isolated (warn and continue) and skippable when a calling skill lists them in metadata.skip_stages. The legacy stage IDs orphan-check and compaction-check are recognized as sub-steps of budget-eval for backward compatibility.

The six pre-skill pipeline stages, in execution order.
Stage Critical? Description Skip Conditions
help No Before any other processing, checks the calling skill's arguments for --help. If present, displays the skill's SKILL-quickguide.md body (or the description frontmatter field as fallback) and stops the whole pipeline. No-op when arguments do not contain --help; listable in skip_stages.
brief-log Yes Obtains UTC time, then inserts a STARTED | <datetime> | <skill> | <brief> entry as the newest line in briefs.md. Sub-steps link the conversation trace and persist brief state for post-skill consumption. Never skipped (critical).
budget-eval Yes Reads the calling skill's metadata.context_budget (default standard) and loads references per tier: light skips all briefs/refs; standard loads the briefs index; heavy loads full briefs with recency windowing plus the plan index. Hosts the orphan-detection and compaction-warning sub-steps. Never skipped (critical); its orphan-check and compaction-check sub-steps are individually skippable.
pending-check No Runs pending.py status --overdue-days 14 --format banner and prints any non-empty output verbatim. Purely informational — never blocks the invocation. Skipped when pending-check is in the skill's skip_stages (e.g. /pending, /publish).
ref-load Yes Loads the mandatory refs (conventions.md, permissions.md, constraints.md) then skill-specific refs — eager-only mode injects every metadata.references entry; demand-pull mode (eager_references present) injects eager refs and lists lazy refs on demand. Applies to standard/heavy tiers only; a light-budget skill skips ref-load entirely.
constitution No Reads and injects product-design/constitution.md for trust-boundary enforcement. Skipped silently if the file is absent; also skipped for light-budget skills and when constitution is in skip_stages.

Post-skill pipeline

Post-skill runs an ordered sequence of numbered steps (with lettered sub-steps) that update state, log Q&A, run safety gates, and commit. The Deferred mode column records what happens under the --deferred flag, which the roadmap parallel-wave orchestrator passes after merging a worktree branch back to main: only the per-plan state alignment that needs the merged code runs; the orchestrator owns wave-level briefs, docs, Q&A, and commits. Under --deferred, only steps 0, 1b, 2, 2c, 7, 2g, and 8b execute.

Post-skill pipeline steps, gate conditions, and deferred-mode behavior.
Step ID Name Gate Condition Description Deferred mode
0 Checkpoint recovery Runs if .post-skill-checkpoint exists Reads the checkpoint (<step> | <datetime> | <skill-id>); resumes from the step after <step> when the skill-id matches, else deletes the stale file. Run
1 Brief-log (mark DONE) Always Obtains UTC time, loads the persisted brief, and marks the matching STARTED entry DONE (appending | PLAN | <id> where applicable). Skip — orchestrator writes the wave-level brief
1b Telemetry prep Always Prepares an in-context telemetry record (flushed to disk at 8b) per the telemetry schema. Run (flushed at 8b)
2 As-Coded alignment Parent skill is implement Reads the plan and incrementally updates product-design-as-coded.md Conceptual Design, plus DONE-marker proposals and changelog appends. Skipped when parent is plan (no code yet). Run — merged code is now on main
2b Documentation auto-run Same gate as step 2 Collects non-N/A Docs: fields and offers to run /document --plan <id> now, or files an update-documentation pending entry on Skip. Skip — orchestrator handles wave-level docs
2c Design intent reminder Same gate as step 2 Informational nudge to promote implemented design-intent items to established via /explain drift --promote. Does not perform the promotion. Run
2d Eager implement entry Parent is /plan and brief carries PLAN | <id> Files an idempotent implement pending entry from the completed plan so the next step is queued. Skip — not from /plan
3 Q&A log Unless skip_qa_log Three branches: skip; inline in the artifact file (plan/implement/roadmap/critique); or companion -qa- file (default, all other artifact types). Skip — orchestrator handles wave-level Q&A
4 Commit message Always Creates a commit message including the artifact ID. Skip — orchestrator commits atomically
5 Git-state safety check Always Runs git status; refuses to commit during a rebase, on an unmerged conflict, or with detached HEAD; warns and asks for confirmation on main/master. Skip — orchestrator commits atomically
6 Commit scope verification Always Runs verify_commit_scope.py to check staged files against expected paths; warns on unexpected pre-staged files. Skip — orchestrator commits atomically
6b Fast preflight gate Always Runs run_preflight_fast.py; advisory (not blocking — the pre-commit hook is the hard gate). Skip — orchestrator runs preflight once for the wave
6c Human markers verifier Always Runs check_human_markers_only.py --staged; on prose mutation in a Human (markers) file, asks whether to abort or proceed. Skip — orchestrator runs markers check once for the wave
7 Index regeneration Always Refreshes the briefs index and macro INDEX.md, updates cross-references, and conditionally regenerates the decision digest. Run
2g Pending action creation Same gate as step 2 Files verify-as-coded, test-implementation, and update-documentation pending actions from plan metadata; unconditionally closes the implement entry as a mark-done safety net. Run
7e Deferred-artifact generation Parent skill is implement Maintains the plan's ## Manual Actions section and generates _output/docs/deploy.html from non-N/A Deploy: fields, before the step-8 commit. Skip — orchestrator handles wave-level docs
8 Commit Always Stages affected files (indexes, as-coded updates, step-7e artifacts) and commits; deletes the checkpoint on success. Skip — orchestrator commits
8b Telemetry flush Only if step 8 produced a commit Enriches the 1b record with commit-dependent fields and appends it as a separate trailing telemetry: commit; drops the record if no primary commit occurred. Run (appended; orchestrator includes it in the wave commit)
9-12 Wrap-up & next-step Always Reports surprises, links the generated file, prints the SKILL COMPLETE banner, and offers contextual next-step suggestions from the skill graph. Skip
